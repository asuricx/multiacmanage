# 🚀 سامانه جامع اتوماسیون یوزربات تلگرام (Telegram Userbot Automation Platform)

یک پلتفرم ماژولار، مقیاس‌پذیر و توزیع‌شده با معماری تمیز (Clean Architecture) جهت مدیریت گروهی اکانت‌های تلگرام، استخر خودکار پروکسی، ثبت ری‌اکشن‌های ارگانیک، استارت رفرال بات‌ها و سیستم پشتیبان‌گیری خودکار.

---

## 🛠 پشته فنی (Tech Stack)
- **زبان و فریمورک:** Python 3.12 + Kurigram / Pyrogram v2 (پشتیبانی کامل از سشن‌های رشته‌ای و فایل‌های `.session` تلتون و پایروگرام)
- **پایگاه داده:** PostgreSQL 16 به همراه Async SQLAlchemy 2.0 و Alembic (مایگریشن‌های خودکار)
- **کش و FSM:** Redis 7 برای صفوف و مدیریت استیت‌های گفتگوی ربات (FSM)
- **زمان‌بندی و تسک‌ها:** APScheduler جهت اجرای دوره‌ای اسکرپر پروکسی، تست سلامت اکانت‌ها و بک‌آپ دیتابیس
- **استقرار و داکر:** Docker & Docker Compose برای اجرای یکپارچه بدون وابستگی به سیستم‌عامل

---

## ✨ امکانات و ماژول‌های پیاده‌سازی شده

### ۱. ماژول مدیریت یوزربات‌ها (Accounts Management)
- **افزودن اکانت به ۳ روش:**
  1. ارسال دسته‌ای سشن‌های متنی (چندگانه / تک) با تشخیص خودکار فرمت (Pyrogram v1, Pyrogram v2, Telethon IPv4/IPv6).
  2. آپلود فایل سشن (`.session`) تولید شده توسط نرم‌افزارهای تلتون یا پایروگرام با استخراج مستقیم کلید احراز هویت.
  3. ورود تعاملی با شماره تلفن (ارسال کد تایید تلگرام و رمز عبور دومرحله‌ای 2FA درون ربات).
- **تست سلامت گروهی و تکی:** بررسی وضعیت اکانت‌ها (`ACTIVE`, `BANNED`, `FLOOD_WAIT`, `INVALID`).
- **پاک‌سازی سشن‌های معیوب:** حذف خودکار اکانت‌های غیرفعال یا بن‌شده با تایید ادمین.

### ۲. استخر هوشمند پروکسی (Proxy Pool & Scraper)
- **اسکرپ خودکار پروکسی:** اسکرپ هر ۱۲ ساعت یک‌بار از کانال‌های تلگرامی معین.
- **استخراج عمیق از دکمه‌های شیشه‌ای:** استخراج لینک‌های پروکسی از متن پست‌ها و دکمه‌های اینلاین شیشه‌ای (MTProto, SOCKS5, HTTP).
- **پایش سلامت و چرخش خودکار:** تست سلامت و پینگ دوره‌ای پروکسی‌ها، حذف پروکسی‌های مرده و انتصاب پروکسی سالم به هر اکانت.
- **اتصال مستقیم (Fallback):** در صورت نبود پروکسی فعال، اکانت‌ها بدون وقفه با آی‌پی اصلی سرور کار می‌کنند.

### ۳. ماژول ری‌اکشن هوشمند (Smart Reactions)
- **معماری تک‌ناظر (Single Watcher):** فقط ۱ اکانت پست‌های کانال را پایش می‌کند تا مصرف منابع به حداقل برسد.
- **انتخاب تصادفی وزنی ایموجی‌ها:** قابلیت انتخاب چند ایموجی دلخواه با تخصیص کاملاً تصادفی و غیریکنواخت روی هر پست.
- **فیلتر تاریخی و تاخیر ارگانیک:** پشتیبانی از پست‌های امروز، ۳ روز گذشته یا ۷ روز گذشته به همراه فواصل تاخیر شناور تصادفی برای رفتار شبیه انسان.

### ۴. ماژول استارت رفرال بات (Referral Bot Joiner)
- **پشتیبانی کامل از لینک و یوزرنیم:** تشخیص خودکار ربات هدف و پارامتر رفرال از لینک کامل تلگرام (مانند `https://t.me/Bot?start=ref_123`).
- **جلوگیری از عضویت تکراری:** ثبت تاریخچه عضویت در جدول `join_logs`؛ اکانت‌هایی که قبلاً ربات را استارت زده‌اند مجدداً فراخوانی نمی‌شوند.
- **روش عضویت دومرحله‌ای:** ارسال درخواست MTProto `StartBot` با فال‌بک خودکار به دستور متنی `/start <param>`.
- **پخش ارگانیک در بازه زمانی (Time Window):** قابلیت پخش عضویت اکانت‌ها در بازه زمانی دلخواه (مانند ۱۰۰ کاربر در ۱ ساعت) با تاخیرهای شناور تصادفی ارگانیک.

### ۵. سیستم پشتیبان‌گیری خودکار دیتابیس (Automated Database Backup)
- **استخراج استاندارد PostgreSQL:** استفاده مستقیم از `pg_dump` و فشرده‌سازی خروجی با الگوریتم GZIP (`.sql.gz`).
- **زمان‌بندی ۲۴ ساعته:** ارسال خودکار فایل بک‌آپ دیتابیس هر ۲۴ ساعت یک‌بار به تلگرام ادمین‌ها.
- **پاک‌سازی فوری از روی دیسک سرور:** بلافاصله پس از ارسال فایل به تلگرام، نسخه محلی از روی سرور حذف می‌شود تا حجم دیسک اشغال نگردد.
- **دکمه دریافت آنی:** امکان دریافت دستی آخرین نسخه بک‌آپ در هر زمان از طریق پنل ربات.

## 📂 ساختار پروژه (Clean Architecture)

```
.
├── app/
│   ├── core/              # پیکربندی، دیتابیس Async و Redis
│   │   ├── config.py
│   │   ├── database.py
│   │   └── redis.py
│   ├── models/            # جداول SQLAlchemy (Account, Proxy, Reactions, Referral, Logs)
│   ├── handlers/          # هندلرهای پیام و کالبک‌های پنل ادمین
│   ├── services/          # منطق تجاری (Account, Proxy, Reaction, Referral, Backup)
│   ├── tasks/             # تسک‌های پس‌زمینه، وورکرها و زمان‌بند APScheduler
│   └── utils/             # FSM، کیبوردهای شیشه‌ای و مبدل سشن‌ها
├── alembic/               # نسخه‌های مایگریشن ساختار دیتابیس
├── tests/                 # ۱۹ تست واحد جامع برای تمامی ماژول‌ها
├── docker-compose.yml     # فایل اجرای کانتینرهای Bot, Postgres, Redis
├── Dockerfile             # ایمیج اختصاصی ربات بر پایه پایتون ۳.۱۲
├── requirements.txt       # پکیج‌ها و وابستگی‌های پایتون
└── .env.example           # نمونه متغیرهای محیطی
```

## 🚀 راهنمای انتقال و اجرای پروژه روی سرور دیگر (Server Migration Guide)

### گام ۱: آماده‌سازی سرور جدید
ابتدا در سرور جدید پکیج‌های پایه و داکر را نصب کنید:
```bash
sudo apt update && sudo apt install -y curl git rsync
# نصب Docker و Docker Compose
curl -fsSL https://get.docker.com -o get-docker.sh && sh get-docker.sh
```

### گام ۲: انتقال فایل‌های پروژه
در سرور مبدأ، فایل‌های پروژه را با دستور زیر فشرده کرده یا مستقیماً به سرور جدید منتقل نمایید:
```bash
# ایجاد آرشیو از پروژه (به استثنای کش‌ها و محیط مجازی)
tar --exclude='.venv' --exclude='__pycache__' --exclude='backups/*' -czvf userbot_platform.tar.gz -C /root/gem .

# انتقال به سرور جدید با scp (به جای NEW_SERVER_IP آی‌پی سرور جدید را وارد کنید):
scp userbot_platform.tar.gz root@NEW_SERVER_IP:/root/
```

در سرور جدید:
```bash
mkdir -p /root/gem && cd /root/gem
tar -xzvf /root/userbot_platform.tar.gz -C /root/gem
```

### گام ۳: تنظیم متغیرهای محیطی (`.env`)
فایل `.env` را ایجاد و اطلاعات تلگرام خود را در آن وارد کنید:
```bash
cp .env.example .env
nano .env
```
اطلاعات کلیدی که باید وارد کنید:
- `API_ID` و `API_HASH`: از پنل [my.telegram.org](https://my.telegram.org)
- `BOT_TOKEN`: از ربات [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS`: شناسه عددی تلگرام شما (مثال: `123456789`)
- `POSTGRES_PASSWORD`: یک رمز عبور امن برای پایگاه داده

### گام ۴: راه‌اندازی و بیلد با Docker Compose
با اجرای دستور زیر، کل سرویس‌ها (ربات، دیتابیس Postgres و کش Redis) به صورت خودکار بیلد و بالا می‌آیند و مایگریشن‌های دیتابیس نیز به شکل اتوماتیک اعمال می‌شوند:
```bash
docker compose up -d --build
```

وضعیت کانتینرها را با دستور زیر بررسی کنید:
```bash
docker compose ps
```

مشاهده لاگ‌های زنده ربات:
```bash
docker compose logs -f bot
```

## 🔄 نحوه بازگردانی بک‌آپ دیتابیس در سرور جدید (Database Restore)
اگر فایل بک‌آپ ارسالی از تلگرام (`backup_userbot_YYYYMMDD_HHMMSS.sql.gz`) را دارید و می‌خواهید اکانت‌ها و اطلاعات قبلی را در سرور جدید برگردانید:

1. فایل بک‌آپ را در سرور جدید در مسیر پروژه قرار دهید.
2. با دستور زیر آن را درون دیتابیس ایمپورت کنید:
```bash
gunzip -c backup_userbot_YYYYMMDD_HHMMSS.sql.gz | docker compose exec -T postgres psql -U userbot -d userbot_db
```
3. کانتینر ربات را ری‌استارت کنید:
```bash
docker compose restart bot
```
تمام اکانت‌ها، پروکسی‌ها و تنظیمات بدون هیچ نقصی در دسترس خواهند بود! ✅
